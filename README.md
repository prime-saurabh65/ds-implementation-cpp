# Data Structures Implementation in C++

A structured collection of **Data Structures and Algorithms implementations in C++**, created for understanding core data structures, practicing implementation from scratch, and strengthening problem-solving fundamentals.

This repository focuses on implementing fundamental data structures manually rather than relying only on STL containers. It is organized topic-wise to make the learning path easy to follow and revisit.

---

## Overview

The repository contains C++ implementations and practice programs covering:

- Arrays
- Deep Copy
- Dynamic Arrays
- Singly Linked Lists
- Doubly Linked Lists
- Circular Linked Lists
- Circular Doubly Linked Lists
- Stacks
- Priority Queue
- Trees
- Binary Search Trees
- Recursion
- Graph-related topics and practice
- Additional implementation exercises

The repository is continuously evolving as new concepts and implementations are added.
